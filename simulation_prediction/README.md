# Simulation: out-of-sample prediction (Section IV-F)

The manuscript reports only the test AUC from this experiment (Section IV-F). AUC uses the raw
scores, so the calibration set and Platt scaling described below do not affect it; they only feed
the other measures, which are computed here but not reported in the manuscript.

Prediction accuracy of all four methods when the true model is known. Complements the
estimation-error results of Fig. 1.
Because the generating model is known, no outer cross-validation is needed: each fit is scored
on a large independent test set, and the predicted probabilities are compared with the true ones.

## Design

- **Model:** the one in Fig. 1(a)–(e) (`../fig1_simulations/a-e_heatmaps/getEstimates.m`):
  p = 60, three blocks (5×5 at +γ, 5×5 at −γ, 4×4 at +γ), **γ = 0.5**, intercept β = 1,
  **n = 300** training subjects. Symmetric Gaussian matrices, each entry z-scored across the
  training subjects, zero diagonals, y ~ Bernoulli(logistic(⟨A, B⟩ + β)).
- **Test set:** nTest = 5000 subjects from the same model (separate random stream), standardized
  with the **training** means and SDs.
- **Calibration set:** n = 300 further subjects (third stream), used only to Platt-scale SpINNEr's
  least-squares score. Its training scores can't be used for this: they often separate the
  training responses perfectly and the Platt coefficients diverge. Using independent data gives
  SpINNEr the best calibration it could have, so differences in probability measures are conservative.
- **Replicates:** 50, seeded (replicate r uses seeds 20261023 + r, + 100000 + r, + 200000 + r),
  so every replicate can be regenerated exactly (`generate_replicate.m`).
- **Fitting:** `spinner` with the Fig. 1 settings (10 × 10 grid, 5-fold CV, `maxIters = 100`) on the
  toolbox in `../software_84509f9` (commit `84509f9`).

## Measures (`prediction_measures.m`)

| Measure | Meaning |
|---|---|
| `AUC`, `oracleAUC` | test AUC of the fitted score; of the true η (best achievable) |
| `excessKL` | mean KL(p ‖ p̂) = expected test log-loss minus Bayes log-loss (0 = perfect) |
| `logLoss`, `bayesLogLoss` | test log-loss of p̂ and of the true p on the observed y |
| `brier`, `bayesBrier` | Brier score of p̂ and of the true p |
| `probMSE` | mean (p̂ − p)² |
| `corrEta` | Pearson correlation of the fitted score with the true η |
| `calSlope` | slope of logistic regression of y on logit(p̂); 1 = calibrated, > 1 = over-shrunk |
| `relFrobError` | ‖B̂ − B‖_F / ‖B‖_F, as in Fig. 1 |

p̂ = logistic(η̂) for the logistic methods and Platt-scaled score for SpINNEr. An empty fit
(constant score) gets AUC 0.5, `corrEta` 0 and `calSlope` NaN.

## How to run

```matlab
cd simulation_prediction
run_sim_prediction([], true);   summarize_sim_prediction(true);   % quick check, ~3 min
run_sim_prediction();                                               % full experiment
summarize_sim_prediction();
```

- 200 fits (4 methods × 50 replicates); every fit is saved as `results/fit_<method>_rep<r>.mat`
  as soon as it finishes, and re-running skips completed fits.
- The quick check (2 replicates, 3 × 3 grids, nTest = 1000) writes to `results_smoke/`; its numbers
  are meaningless.

## Outputs (`results/`)

| File | Contents |
|---|---|
| `config.mat` | configuration (re-runs stop if it changed) |
| `fit_<method>_rep<r>.mat` | all measures, B̂ (sparse), β̂, chosen λ, Platt coefficients, run time |
| `sim_prediction_summary.csv` | mean and SE over replicates of every measure, per method |
| `sim_prediction_paired.csv` | paired differences from Logistic SpINNEr (AUC, excess KL, corr), share of replicates where Logistic SpINNEr is better, Wilcoxon signed-rank p-value |
| `sim_prediction_boxplots.pdf` | box plots of test AUC (with oracle), excess KL, corr(η̂, η), calibration slope |
| `run_log.txt` | console log of the full run |

Only the two summary CSVs of the manuscript run are included in this repository; the per-fit files are
regenerated by `run_sim_prediction()`.
