# Logistic SpINNEr

Code for the manuscript

> D. Brzyski, A. Cohen, Z. Wang, M. Dzemidzic, D. A. Kareken, J. Harezlak,
> *Joint Nuclear and ℓ1 Regularization for Logistic Matrix Regression with Applications to Brain Imaging*
> (manuscript under review).

Logistic SpINNEr is scalar-on-matrix logistic regression with joint nuclear-norm and ℓ1 penalties,

    argmin_{B, β}  −ℓ(B, β) + λ_N ‖B‖_* + λ_L ‖W ∘ B‖_1,

solved by ADMM with an IRLS subproblem whose steps reduce to n × n linear systems (Algorithm 1 of the
manuscript). This repository holds the MATLAB toolbox and the code behind every figure and reported number
in the manuscript. Large result files are not included; every one of them can be regenerated by the scripts.

## Requirements

MATLAB (the recent runs used R2025a) with the Statistics and Machine Learning Toolbox and, for the
cross-validated fits, the Parallel Computing Toolbox. All scripts locate the toolbox and their inputs relative
to their own folder, so they run from a clone without editing.

## Using the toolbox

```matlab
addpath('software')
sp = spinner(y, ones(n, 1), A);            % A is p x p x n, symmetric with zero diagonals; ones(n,1) adds an intercept
sp.fit('Family', 'Binomial');              % Logistic SpINNEr; both lambdas chosen by cross-validation
sp.Estimate.B                              % estimated coefficient matrix
spinner()                                  % lists all options and their defaults
```

The four methods compared in the manuscript are:

| Method | Options |
|---|---|
| Logistic SpINNEr | `'Family', 'Binomial'` |
| SpINNEr (least squares on the 0/1 response) | `'Family', 'Gaussian'` |
| Logistic LASSO | `'Family', 'Binomial', 'LambdaN', 0` |
| Logistic NUCLEAR | `'Family', 'Binomial', 'LambdaL', 0` |

The experiments use `maxIters = 100` ADMM iterations (the default is 50000) and 10 × 10 (simulations) or
15 × 15 (real data) λ grids; copy the settings from the relevant script.

## Reproducibility notes

- **Toolbox versions.** Commit `3f07a54`, between `84509f9` and `b4fc36b`, corrects the step size in the
  nuclear-norm solvers. This changes Logistic NUCLEAR fits and can shift the cross-validated λ grids of all
  logistic methods, which is why the scripts for Fig. 1, Figs. 5–6 and the simulation prediction point to
  `software_84509f9/`. The relocation runs of Figs. 2–3 used a toolbox download from August 2026 whose commit
  was not recorded; it most likely already contained `3f07a54`, and the scripts point to `software/`.
- **Seeds.** Figs. 1(f), 2–4, the simulation prediction experiment and the real-data comparators are seeded. Figs. 1(a)–(e), 1(g) and the
  bootstrap of Figs. 5–6 were run without a fixed seed, so a rerun reproduces them only up to Monte Carlo
  variation.
- **Paths.** The original scripts used absolute paths on the machines they ran on; in this repository they were
  replaced by paths relative to each script. Apart from this and from comments, the experiment code is as run.
- **Included results.** Small summary files that the plotting scripts read (the Fig. 1 result files, the
  Figs. 2–3 summary CSVs, the Fig. 4 λ values and summary CSV, and the simulation prediction summary CSVs) are
  included, so the figures can be redrawn without rerunning the fits. The real-data comparators include the
  group-level summary CSVs behind the numbers reported in Section V, but no subject-level results.
